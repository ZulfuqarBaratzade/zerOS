# zerOS

**zerOS** is an experimental Linux distribution based on Debian 13 (Trixie), featuring the GNOME desktop environment.

## Features
- Debian 13 base
- GNOME desktop
- Custom branding
- Azerbaijani localization (in progress)
- Live ISO support

## Status

**Alpha — Under Development**

The first Alpha ISO has been built and successfully booted in VirtualBox.
